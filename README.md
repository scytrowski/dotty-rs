# dotty-rs

An experimental implementation of Scala 3 compiler infrastructure in Rust.

`dotty-rs` explores how parts of the Scala 3 compiler can be modeled and implemented in Rust, with a focus on compiler architecture, type-system internals, and interoperability with the existing Scala ecosystem.

The project is being developed incrementally and is currently a work in progress.

## Status

Early development.

The repository contains working pieces of compiler infrastructure, but it is not intended for production use and does not currently aim to be a drop-in replacement for the Scala 3 compiler.

Expect APIs, architecture, and scope to change as the project evolves.
